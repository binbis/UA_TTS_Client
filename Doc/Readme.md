# UA TTS Client Full Cycle - Посібник користувача

    Цей застосунок дозволяє якісно озвучувати українські тексти (у тому числі великі книги, статті чи документи) за допомогою передової нейромоделі StyleTTS2 та зручного віконного клієнта на базі C#.

`Проєкт складається з двох частин:`
- Локальний Сервер (Python): Відповідає за обробку тексту, нормалізацію, розстановку наголосів та генерацію звуку.
- Клієнт (C#): Зручний інтерфейс для керування текстом, налаштування голосів, експорту та прослуховування.

# 🛠 Інсталяція та Запуск

## Windows 11

### Крок 1: Підготовка сервера (Python)

- Впевніться, що у вас встановлено Python (рекомендовано 3.10+).
- Зайдіть у папку python.

- Створіть віртуальне середовище та встановіть залежності (якщо ви цього ще не зробили):
``` bash
python -m venv venv
source venv/Scripts/activate 
```

- Після того як ви увійшли до venv завантажуємо пакети
``` bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
```

- Це перевірка для увімкнення gpu
``` bash
python -c "import torch; print('CUDA доступна:', torch.cuda.is_available()); print('Відеокарта:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else '---')" 
```

- Запуск сервера
``` bash
python server.py
```

## Linux - Arch

### Налаштування прав доступу (Wayland / EndeavourOS)

1. **Встановлення пакетів:** Термінал.
Переконайтеся, що всі необхідні утиліти встановлені.

```bash
### для wayland
sudo pacman -S ydotoold
### для TextCopy
sudo pacman -S wl-clipboard xsel

```

2. **Надання прав користувачу:** Група input.
Щоб `ydotool` міг звертатися до віртуальної клавіатури в ядрі (`/dev/uinput`) без root-прав, додайте свого користувача до системної групи `input`:

```bash
sudo usermod -aG input $USER
```

3. **Запуск системного демона:** systemd.
Для роботи `ydotool` у фоні повинен постійно працювати його демон. Увімкніть його автозапуск на рівні системи:

```bash
systemctl --user enable --now ydotool
```

3.1 **Перевірка статусу:
Щоб переконатися, що демон успішно працює, виконайте:

```bash
systemctl --user status ydotool
```

Після цього ydotool буде готовий до роботи, а демон автоматично запускатиметься при кожному вході в систему.

4. **Перезавантаження системи:** Обов'язково.
Щоб нові права групи `input` застосувалися до вашого користувача, найпростіше повністю перезавантажити комп'ютер (або вийти та зайти в сеанс користувача).

#### Тест запису/читання:
``` bash
echo "Тестовий текст" | wl-copy
wl-paste
```

- Якщо wl-paste виводить "Тестовий текст", то консольний доступ працює.
- Перевірка блокування фоновими процесами: Спробуйте виконати команду з затримкою, переключивши фокус на інше вікно:

``` bash
sleep 3 && wl-paste
```
- Якщо текст виводиться навіть тоді, коли термінал втратив фокус — жорстких системних обмежень на читання буфера з фону зараз немає.
- Пакет для аналізу аудіо-рушія ManagedBass

``` bash
yay -S bass
```
